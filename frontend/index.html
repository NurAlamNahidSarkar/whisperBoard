The Anonymity Guarantee

When you send a message, the frontend sends { to, message } — nothing else. The backend stores only recipient, message, hash (random number), and created_at. There is no sender column in the database. Even with full database access, no one — including the developer — can determine who sent what.

✓ No login required ✓ No cookies tracked ✓ No IP logged ✓ No sender column in DB

Community Guidelines

WhisperBoard is for honest, constructive communication. Messages promoting harassment, personal threats, or targeted abuse violate community standards. Anonymity is a privilege — use it responsibly.
